# 📁 Тестові файли для імпорту

## 📋 Опис

Ця папка містить тестові файли для перевірки функціоналу імпорту прокатів.

## 📄 Файли

### `test_rentals_import.xlsx`
Excel файл з тестовими даними для імпорту прокатів.

### `test_rentals_import.csv`
CSV файл з тестовими даними для імпорту прокатів.

## 📊 Структура даних

Файли містять такі колонки:
- **Клієнт** - ПІБ клієнта (обов'язково)
- **Телефон** - номер телефону (опціонально)
- **Email** - електронна пошта (опціонально)
- **Автомобіль** - формат: `Brand Model (Year)` (обов'язково)
- **Дата початку** - дата початку прокату (обов'язково)
- **Очікувана дата завершення** - дата завершення прокату (обов'язково)
- **Статус** - статус прокату (опціонально): Активний / Завершено / Скасовано

## ⚠️ Важливо!

**Автомобілі в тестових файлах повинні існувати в базі даних!**

Тестові файли використовують такі автомобілі (з seed.ts):
- Toyota Corolla (2020)
- BMW 3 Series (2022)
- Mercedes-Benz C-Class (2021)
- BMW X5 (2023)
- Mercedes-Benz S-Class (2023)

Якщо ці автомобілі не існують в вашій базі даних, виконайте:
```bash
npm run seed
```

## 🧪 Тестові сценарії

Файли містять різні тестові сценарії:
1. ✅ Повні дані (клієнт, телефон, email)
2. ✅ Без телефону (тільки email)
3. ✅ Без email (тільки телефон)
4. ✅ Різні формати дат (DD.MM.YYYY та YYYY-MM-DD)

## 🚀 Як використовувати

1. Переконайтесь, що автомобілі існують в базі даних
2. Відкрийте діалог "Імпорт прокатів" на сторінці прокатів
3. Завантажте один з тестових файлів
4. Перевірте результат імпорту

## 🔄 Регенерація файлів

Щоб згенерувати нові тестові файли:
```bash
node scripts/generate-test-import-file.js
```

Файли будуть створені в папці `backend/test-files/`.
