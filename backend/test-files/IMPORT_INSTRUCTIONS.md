# 📋 Інструкції для тестування імпорту

## ⚠️ Важливо перед імпортом!

### 1. Переконайтесь, що автомобілі існують в базі даних

Виконайте seed, якщо база порожня:
```bash
npm run seed
```

**Автомобілі, які мають бути в базі:**
- Toyota Corolla (2020)
- BMW 3 Series (2022)
- Mercedes-Benz C-Class (2021)
- BMW X5 (2023)
- Mercedes-Benz S-Class (2022)

### 2. Перевірте дати в файлі

Тестові файли автоматично генеруються з **майбутніми датами** (починаючи з завтра).

Якщо ви хочете згенерувати нові файли з актуальними датами:
```bash
node scripts/generate-test-import-file.js
```

## 🧪 Як тестувати

1. **Відкрийте сторінку прокатів** (`/rentals`)
2. **Натисніть "Імпорт"**
3. **Завантажте тестовий файл:**
   - `backend/test-files/test_rentals_import.xlsx` або
   - `backend/test-files/test_rentals_import.csv`
4. **Перевірте результат:**
   - Скільки прокатів успішно імпортовано
   - Чи є помилки
   - Перевірте створені прокати в списку

## 🔍 Типові помилки та рішення

### "Start date cannot be in the past"
**Причина:** Дати в файлі в минулому  
**Рішення:** Згенеруйте новий тестовий файл:
```bash
node scripts/generate-test-import-file.js
```

### "Автомобіль не знайдено"
**Причина:** Автомобіль не існує в базі  
**Рішення:** Запустіть seed:
```bash
npm run seed
```

### "Car is already booked for the selected dates"
**Причина:** Автомобіль вже заброньований на ці дати  
**Рішення:** Використайте інші дати або інший автомобіль

## 📝 Примітки

- Тестові файли автоматично генеруються з майбутніми датами
- Дати починаються з завтрашнього дня
- Кожен наступний прокат має дати через кілька днів після попереднього
- Файли містять різні тестові сценарії (з телефоном, без телефону, з email, без email)
